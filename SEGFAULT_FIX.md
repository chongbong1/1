# Исправление Segmentation Fault для больших N

## Проблема

При числе частиц 10000-40000 программа выдавала **segmentation fault** из-за переполнения буферов ячеек.

### Причина

Фиксированная вместимость ячеек была жестко закодирована как 500 частиц:

```fortran
sys%cells(i,j)%capacity = 500  ! multipole_2d_log.f90:110
```

Для N=40000 в сетке 7×7 (49 ячеек):
- Средняя плотность = 40000/49 ≈ **816 частиц/ячейку**
- Вместимость = 500 → **ПЕРЕПОЛНЕНИЕ на 63%**

Это приводило к:
1. Записи за пределы массива `particle_ids[]` → segfault
2. Молчаливой потере частиц в `update_cell_assignments`
3. Невалидным индексам в вычислительных циклах

---

## Решение

Реализован **динамический расчет вместимости** на основе числа частиц и размера сетки:

```fortran
capacity = ceiling((N / n_cells) × safety_factor)
```

где:
- N = max_particles
- n_cells = nx × ny
- safety_factor = 3.0 (запас для неравномерного распределения)

### Изменения в коде

#### 1. Новая функция расчета вместимости

**Файл:** `multipole_2d_log.f90` (после строки 130)

```fortran
function calculate_cell_capacity(n_particles, n_cells, safety_factor) result(capacity)
  integer, intent(in) :: n_particles, n_cells
  real(dp), intent(in) :: safety_factor
  integer :: capacity
  integer :: avg_per_cell

  avg_per_cell = ceiling(real(n_particles, dp) / real(n_cells, dp))
  capacity = ceiling(real(avg_per_cell, dp) * safety_factor)
  capacity = max(capacity, 100)    ! Минимум
  capacity = min(capacity, 50000)  ! Максимум
end function calculate_cell_capacity
```

#### 2. Модифицирован `init_system`

**Файл:** `multipole_2d_log.f90:81-130`

Добавлено:
- Вычисление `cell_capacity` на основе `max_part` и размера сетки
- Вывод информации о вместимости ячеек
- Использование динамической вместимости вместо константы 500

#### 3. Проверка границ в `add_particle`

**Файл:** `multipole_2d_log.f90:204-216`

Добавлена проверка перед записью в `particle_ids[]`:
```fortran
if (sys%cells(ci,cj)%n_particles >= sys%cells(ci,cj)%capacity) then
  ! Вывод подробного сообщения об ошибке
  stop 1
end if
```

#### 4. Обработка переполнения в `update_cell_assignments`

**Файл:** `multipole_2d_log.f90:707-760`

Вместо молчаливого пропуска частиц:
- Подсчет количества потерянных частиц
- Вывод детального сообщения об ошибке
- Остановка программы с понятным объяснением

## Использование

### Стандартный запуск
```bash
make
./vortex_fmm
```

Программа автоматически рассчитает необходимую вместимость ячеек.

### Для больших N (10000+)

Измените в `main_vortex.f90`:
```fortran
n_per_side = 100  ! 100×100 = 10000 частиц
n_cells = 7       ! или увеличьте для лучшей производительности
```

### Рекомендации по размеру сетки

```
n_cells ≈ sqrt(N / 50)
```

Примеры:
- N=100 → сетка 7×7
- N=1000 → сетка 7-10×7-10
- N=10000 → сетка 15-20×15-20
- N=40000 → сетка 20-30×20-30

### Обработка ошибок

Если получите сообщение "Cell capacity exceeded":
1. Увеличьте размер сетки (`n_cells`)
2. Уменьшите шаг по времени (`dt`) если это динамика
3. Проверьте равномерность распределения частиц

## Технические детали

### Расчет памяти

| N | Сетка | Вместимость | Память на ячейки |
|---|-------|-------------|------------------|
| 100 | 7×7 | 100 | ~20 KB |
| 1000 | 7×7 | 100 | ~20 KB |
| 10000 | 7×7 | 615 | ~120 KB |
| 40000 | 7×7 | 2451 | ~480 KB |
| 40000 | 20×20 | 300 | ~470 KB |

Память на ячейки незначительна по сравнению с массивом частиц (N × 64 байта).

### Коэффициент безопасности

Safety factor = 3.0 покрывает:
- Равномерное распределение: плотность = среднее ± 0
- Умеренное кластеризация: плотность = среднее × 2
- Сильное кластеризация: плотность = среднее × 3

Для равномерного распределения 40000 частиц:
- Средняя плотность: 816 частиц/ячейку
- Вместимость: 2451 (запас ×3)
- Стандартное отклонение при равномерном: ~28
- Покрытие: 3σ = 84 частицы (защита от флуктуаций)
