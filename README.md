✅ **Работает с машинной точностью!** (ошибка ~10⁻¹⁴)

## 🔬 Физика

- **Потенциал:** φ = -q·log(r)
- **Сила:** F = q·r/r²
- **Применение:** Вихри в сверхпроводниках типа II
