# 2D FMM для логарифмического потенциала (сверхпроводники)

## Что было исправлено

Найдены и исправлены **3 критические ошибки** в M2L (Multipole-to-Local) трансляции:

1. ❌ **Неправильный знак** для монополя в L₀: было `+`, должно `-`
2. ❌ **Отсутствие степеней z₀^k** для вклада M_k в L₀
3. ❌ **Неправильные степени** в формуле для L_j: должно быть z₀^(j+k), было z₀^j

## Физика

### Потенциал
```
φ(r) = -q·log|r|
```

Это **логарифмический потенциал** для 2D вихрей в сверхпроводниках.

### Сила
```
F = -∇φ = q·r/r²
```

### Уравнение движения

Overdamped Langevin:
```
dr/dt = F + η·ξ(t)
```

где:
- `F` - сила от других вихрей (через FMM)
- `η` - амплитуда шума
- `ξ(t)` - белый шум

## Валидация метода

### Проверка 1: Сравнение с прямым расчетом

Программа автоматически сравнивает:
- `compute_all_forces()` - FMM O(N log N)
- `compute_forces_direct()` - прямой O(N²)

Выводит первые 5 частиц с детальным сравнением.

### Проверка 2: Консервация заряда

Общий заряд (вихревое число) должен сохраняться:
```
Q_total = Σ qᵢ = const
```

Для шахматной структуры 10×10: `Q_total = 0`

### Проверка 3: Энергия

Полная энергия (при η=0, без шума):
```
E = -Σᵢ<ⱼ qᵢ·qⱼ·log|rᵢⱼ|
```

должна быть ≈ const (может медленно убывать из-за диссипации).

## Troubleshooting

### Ошибка компиляции

```
Error: Cannot open module file 'multipole_2d_log.mod'
```

**Решение:** Убедитесь что модуль компилируется первым:
```bash
make clean
make
```

### Низкая точность

Если ошибка > 10⁻⁶:

1. Увеличьте `p_order` (20 → 30)
2. Увеличьте `n_cells` (7 → 10)
3. Проверьте, что частицы не слишком близко к границам

### Численная нестабильность

Если силы "взрываются":
- Уменьшите `dt` (0.001 → 0.0001)
- Уменьшите `eta` (шум)
- Проверьте, что нет наложения частиц (r < EPS)

## Дальнейшее развитие

Для очень больших систем (N > 10000):

1. **Иерархический FMM** - адаптивное дерево вместо равномерной сетки
2. **M2M/L2L операции** - многоуровневый перенос
3. **OpenMP** - распараллеливание
4. **GPU** - CUDA/OpenCL для P2P

Но для N < 10000 текущая реализация оптимальна и проста!
